# DIRIGENT – Synthesizer & Sequenzer (eigenständiges Testprojekt)

**Wichtig:** Dieser Branch ist ein komplett eigenes, separates Projekt.
Er hat **nichts** mit der Hauptseite „Deutsch mit Xander“ (Branch `main`) zu tun,
teilt keinen Code mit ihr und verändert sie nicht. Er liegt nur aus praktischen
Gründen im selben Repository, damit Xander die App ablegen und ausprobieren kann.

## Inhalt
- `index.html` – die komplette App in einer einzigen Datei (Web Audio, kein Server nötig)

## Funktionen
- 4 Synth-Spuren (VA, FM, Wavetable) + 1 Drum-Spur, 4 Szenen (Clip-Launcher)
- Aufnahme mit Quantisierung, Metronom, Akkord-Erkennung („Chord-Spur“, Follow)
- Transponieren (diatonisch/chromatisch), MIDI-Export (.mid), Speichern im Browser

## Öffnen
`index.html` im Browser öffnen. Ton startet nach dem ersten Tippen.
